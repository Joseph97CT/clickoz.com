Fix JSON parse errors (fast): commas, quotes, trailing commas

If JSON is invalid, APIs fail, config files won’t load, and JSON-LD schema can break. This guide shows a simple routine that works every time: prettify → validate → fix → validate again.

Reading time: ~6–8 min Level: Beginner → Intermediate Use cases: API payloads, configs, JSON-LD

The JSON Fix Routine (do this every time)

  1. Prettify your JSON so the structure is readable.
  2. Validate and focus on the first error (line/column).
  3. Fix one issue (don’t edit everything at once).
  4. Validate again until it’s clean.
  5. Minify only when you’re ready to ship.
Tip that saves time
Most validators show the first failing location. Fixing it usually reveals the next issue immediately.

Common JSON errors (and the exact fix)

1) Missing comma

If you see errors like “Unexpected string” or “Expected ',' or '}'”, it’s often a missing comma between fields.

{
  "name": "Clickoz JSON Formatter"
  "type": "tool"
}

Fix: add the comma.

{
  "name": "Clickoz JSON Formatter",
  "type": "tool"
}

2) Single quotes instead of double quotes

JSON is strict: keys and strings must use double quotes.

{
  'name': 'Clickoz'
}

Fix:

{
  "name": "Clickoz"
}

3) Trailing comma (not allowed)

A trailing comma is a comma that appears right before } or ].

{
  "a": 1,
}

Fix: remove the last comma.

{
  "a": 1
}

4) Mismatched braces or brackets

If something opens, it must close: { } and [ ].

{
  "items": [1, 2, 3
}

Fix:

{
  "items": [1, 2, 3]
}

How to read “line” and “column” errors

Many errors point to where parsing failed (line/column). The real mistake is often right before that point. Prettifying first makes this dramatically easier.

Prettify vs Validate vs Minify

Action What it does Use it when
Prettify Makes JSON readable (indentation + line breaks). Debugging, editing, reviews
Validate Checks strict JSON rules (real “is this valid?”). Always, before you paste/ship
Minify Removes whitespace to reduce size. Production, transfer, storage

JSON for SEO (JSON-LD)

If you’re adding structured data (JSON-LD) to a page, it must be valid JSON. A single trailing comma or wrong quote can make Google ignore the markup.

Quick check
If your schema markup isn’t being detected, validate the JSON first—then re-test.

FAQ

Why does JSON parsing fail?

Most issues are missing commas, single quotes, trailing commas, or mismatched braces/brackets. Fix the first reported error, then validate again.

Are trailing commas allowed in JSON?

No. Remove the final comma inside objects or arrays.

Should I prettify or minify JSON?

Prettify while debugging/editing; minify only when shipping.

Does JSON matter for SEO?

Yes. JSON-LD structured data must be valid JSON or search engines may ignore it.
